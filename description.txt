LIBRARY MANAGEMENT SYSTEM
=========================

Abstract
========
The Library Management System is a Python-based command-line application developed to manage books, 
library members, user accounts, book requests, and borrowing transactions using an SQLite database. 
The system provides two roles, Librarian and Member, where the Librarian performs administrative operations 
and Members interact with the library services. Librarians can manage books and members, review book requests, 
approve or reject requests, issue books, process returns, and view borrowing records. Members can sign in, 
view their profile, search available books, request books, track request status, view currently borrowed books, 
and access their borrowing history. The system uses relational database tables and foreign-key relationships to 
maintain consistent records and supports CRUD operations, authentication, input validation, and exception handling. 
The project demonstrates the practical application of Python programming and SQL database concepts through a 
structured and user-friendly command-line system.

Objective
=========
1. To develop a Python-based library management application using SQLite3 for storing and managing library data.
2. To manage books efficiently, including adding, viewing, searching, updating, and deleting book records.
3. To manage library members and maintain their information in a structured database.
4. To provide secure user authentication through Sign Up and Sign In with separate roles for Librarian and Member.
5. To allow Members to search and view available books and submit requests for books they want to borrow.
6. To allow Librarians to manage book requests by approving or rejecting requests.
7. To manage book issuing and returning and maintain accurate borrowing records.
8. To maintain borrowing history so Members and Librarians can track previous and current book transactions.
9. To implement a relational database using tables, primary keys, foreign keys, and appropriate constraints.
10. To implement CRUD operations, input validation, and exception handling to ensure reliable and consistent application functionality.

Requirements
============

The project is developed using Python and SQLite3.

Conclusion
==========
The Library Management System provides a structured command-line solution for managing books, members, user accounts, 
book requests, and borrowing transactions using Python and SQLite3. The system separates Librarian and Member 
functionalities, allowing the Librarian to manage library operations while Members can search books, submit requests, 
and track their borrowing activities. The implementation of CRUD operations, authentication, book request approval, book 
issuing and returning, database relationships, validation, and exception handling demonstrates the practical application 
of Python and SQL database concepts. Overall, the project provides an organized and user-friendly approach to managing 
library resources and maintaining borrowing records through a relational database.
